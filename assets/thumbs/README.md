# 차트 카드 표지(썸네일)용 사진
종목별 폴더에 지훈 님이 보내준 짤을 모아 둔다. 차트 카드 표지에 한 장만 쓴다(중간 장에는 안 씀).
samsung/: 이재용 회장 짤 (jy01 쉿, jy02 흡족, jy03·jy06 냉철, jy04 안경, jy05 머리 쓸기, jy07 굳은 표정, jy08 윙크, jy09 터번, jy10 출근, jy11 그림자)
hynix/: 최태원 회장 짤 (hx01 진지)
kospi/: 코스피 하락일용 밈 짤 39장(dn01~dn45, 두 장 hold로 이동, 11/23 지훈 님 전달: 버핏, 박명수, 페페, 루피, 강아지·고양이 등). 코스피가 빠진 날 이걸 먼저 쓴다. 이재명 사진은 보류. 총 든 페페(추격매수 죽어야겠습니다)는 자해 연상이라 일부러 뺌.
최근에 쓴 사진은 assets/thumbs/used.json 에 기록해서 연달아 같은 걸 쓰지 않는다.

kospi_hold/: 문제 소지가 있어 뺀 짤(쓰지 않음). dn10 거지 가즈아(실존 인물 사진+가짜 자막), dn11 커피(뉴스 캡처 속 실존 인물). 지훈 님이 쓰라고 하면 kospi/ 로 되돌린다.
11/23 추가로 뺀 것(저장 안 함): 한강 투신 연상 2장(반등이라고?!, 원숭이 한강물), 실존 어린이 사진, 유튜버 화면 캡처.

kospi_up/: 코스피 상승일용 짤 13장(up01~up13, 11/23 지훈 님 전달: 가즈아 시리즈, 페페, 루피 등). 코스피가 오른 날 이걸 쓴다. 울며 가즈아 하는 실존 어린이 사진은 뺐다.
